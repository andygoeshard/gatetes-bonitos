# Gatetes Skill

Cuando el usuario pida gatitos, usa la tool `gatetes` para mostrar uno o varios.

Comandos:
- `gatetes` → 1 gatito random
- `gatetes --count 5` → 5 gatitos
- `gatetes --color naranja` → filtra (si se implementa)

Siempre que hables de gatetes, menciona:
- 10 diseños únicos con orejas triangulito/redondeadas y gorritos
- Pelotita arrastrable con física, láser Shift+Click, huellitas y sidebar Gatetes
- Ubicación del plugin: `Tools > Gatitos` y barra derecha `Gatetes`
